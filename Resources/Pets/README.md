# 栖息地物种 Sprite 规格

美术只需要交一批 PNG，放进下面这个目录就自动生效，不用改代码、不用重新打包：

```
~/Library/Application Support/KeyboardWaiter/Pets/
```

目录不存在或缺图时，程序回退到代码画的占位形象，**所以可以一批一批交，不用一次交齐**。

## 这是什么系统

不是「养一只宠物升级」，而是**图鉴收集 + 栖息地**：

- 用户的使用行为会解锁物种（连续三天熬夜 → 夜行种；一天在八个应用间穿梭 → 游牧种）
- 解锁的物种住进桌面上一小片栖息地
- 最近还在做这件事的物种是**活跃**的，不再这么用了就进入**冬眠**

所以每个物种只需要两个状态，不需要成长阶段。

## 文件命名

```
<物种id>.png            活跃态（必需）
<物种id>_dormant.png    冬眠态（可选，没有就用活跃态降透明度）
```

## 物种表

| id | 中文名 | 解锁条件 | 形象方向 |
|---|---|---|---|
| `nightowl` | 夜行种 | 连续三天在凌晨还在敲 | 夜行动物，大眼睛 |
| `earlybird` | 晨光种 | 连续三天清晨就开工 | 精神，带光感 |
| `sprinter` | 疾行种 | 一天敲够两万次 | 前倾、有速度感 |
| `shortcut` | 捷径种 | 修饰键占比超过 15% | 敏捷、带闪电元素 |
| `wanderer` | 远行种 | 一天指针走过 100 米 | 有脚，走了很远的样子 |
| `nomad` | 游牧种 | 一天里在八个应用间穿梭 | 轻盈、不安定 |
| `burrower` | 深耕种 | 一天七成输入集中在一个应用 | 沉稳、扎根 |
| `reviser` | 反复种 | 删除键占比超过 12% | 纠结、反复擦写 |
| `ambidexter` | 双持种 | 键盘和指针各占一半 | 对称、两只手 |
| `marathoner` | 长驻种 | 一天里有十二个小时在动 | 耐力型、不慌不忙 |

**第一批建议先做 5 个**：`sprinter`、`marathoner`、`burrower`、`reviser`、`nightowl`——实测这几个最容易被解锁，用户最早看到的就是它们。

物种会持续增加，这是这个系统的设计前提：加一个物种 = 一条规则 + 一张图。

## 技术要求

| 项 | 要求 |
|---|---|
| 格式 | PNG，带透明通道 |
| 尺寸 | 256 × 256 px（程序按 34–50pt 缩放显示） |
| 留白 | 四周留 8% 安全边距 |
| 对齐 | **所有物种的「脚底」在同一条水平线上**（距底边约 12%），它们要站在同一片地上 |
| 描边 | 必须有，深浅壁纸都要看得清 |
| 辨识度 | **小尺寸下靠轮廓区分**，实际显示只有 40pt 左右，细节会糊 |

最后一条最重要：栖息地里最多同时站 6 只，每只 40pt。**轮廓不同才认得出谁是谁**，靠颜色或纹理区分会全糊在一起。

## 配色

| 用途 | 色值 |
|---|---|
| 主体 | `#DBA847`（琥珀） |
| 线条 / 五官 | `#2E2A1F`（石墨） |
| 地面 | `#E6DBC2` |

允许每个物种在琥珀基调上偏一点色相，但不要跳出这套体系——它们要看起来是同一个世界的生物。

## 冬眠态

如果单独画：闭眼、蜷缩、褪色都可以，但**不要画成死掉或悲伤**。冬眠的含义是「你最近不这么用电脑了」，不是「你做错了」。

不单独画也行，程序会把活跃态降到 45% 透明度。
