# KeyboardWaiter 0.10.0

Pointer tracking now covers every kind of mouse/trackpad input, not just clicks and
vertical scrolling.

- **Cursor movement and drags are counted.** `mouseMoved` and the three drag event
  types were never in the event tap, so a one-finger slide left no trace. A continuous
  stream of move events is collapsed into one count per stroke: a new stroke starts
  after the pointer has been still for 0.4s, which mirrors how a trackpad scroll gesture
  is already counted once per gesture
- **Horizontal scrolling is counted.** Only axis 1 was read before, so a sideways
  two-finger swipe was discarded. Whichever axis moved further now decides the direction
- **New `Pointer Travel` card** adds up how far the cursor moved, shown in meters
  (a rough estimate: it assumes ~110 points per inch, and real screen density varies by
  model). Distance is stored under its own `mt_` key prefix so it never mixes into the
  keyboard or pointer *action* totals, the 24-hour trend, or the calendar grid
- The mouse page is now a 2x5 grid of cards to fit the four new counters plus travel
- `swift build` / `swift test` work again: the app target could not see `AppLocalizer`,
  which made the whole package fail to build outside `scripts/build_binary.sh`. Fixed a
  stale expected timestamp in `HourlyBucketTests` that this uncovered
