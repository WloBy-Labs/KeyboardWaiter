# KeyboardWaiter 0.12.0

Every keystroke and click now records **which app it happened in**.

- **New `Apps` page** ranks apps by input volume, with the keyboard/pointer split and each
  app's share of the total. The menu bar gains a `Top app` line for today.
- App names resolve through `NSWorkspace`, so an app installed on this Mac shows its real
  display name (including localized ones). For data imported from another machine, or an app
  since uninstalled, the name is derived from the bundle id — skipping generic trailing
  segments, so `com.figma.Desktop` reads as `Figma` rather than `Desktop`.
- The frontmost app is tracked through `NSWorkspace.didActivateApplicationNotification` and
  cached; the capture path never queries it per event.
- Pointer Travel stays out of the ranking, since distance is not a count.

## Database migration

`hourly_counts` gains an `app_id` column and its primary key becomes
`(hour_bucket, key_id, app_id)`. SQLite cannot alter a primary key, so the table is rebuilt on
first launch and all existing rows are attributed to `unknown`. Verified against a real 58,531
row / 2.2M count database: row count and totals came through identical, and the rebuild took
24ms.

**Do not downgrade to 0.11.x after upgrading.** The old code upserts on
`ON CONFLICT(hour_bucket, key_id)`, a constraint that no longer exists, so it would silently
fail to record. Existing data is not damaged either way.

Snapshots are now schema version 2 and carry `app_id`. Version 1 snapshots still import, with
their rows attributed to `unknown`.
