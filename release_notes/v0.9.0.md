# KeyboardWaiter 0.9.0

New app icon, matching the layout used across the other WloBy apps.

- **New app icon**: the keyboard and mouse move up to make room for a `WLOBY KB`
  wordmark underneath. Same graphite background as before; `KB` is amber, matching the
  key heatmap in the app
- The wordmark only appears at 128px and above — eight characters in a row turn to mush
  at 16/32px, so those sizes draw the graphic alone
- CI: `actions/upload-artifact` bumped to v6, silencing the Node.js 20 deprecation warning

No functional changes to the app.
